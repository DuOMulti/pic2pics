# Pic2Pics

**简体中文** | [English](README.en.md)

**一键拆长图 · One Pic. Many Pics.**

经常需要把长截图发给 AI 分析，但长图里的文字和细节容易看不清。试了几个工具，都不够方便，于是自己做了一个。

选择图片，自动拆分，一键导出。

- 粘贴截图、拖入图片或选择文件
- 自定义分图数量、高度及重叠区域
- 适配电脑、手机浏览器（移动端仍需持续测试）
- 浏览器本地处理，图片无需上传
