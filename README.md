# Pic2Pics

[简体中文](README.md) | [English](README.en.md)

**本地拆图，不上传。One Pic. Many Pics.**

**[▶ 在线使用 Pic2Pics](https://duomiantl.github.io/pic2pics/)**

经常需要把长截图发给 AI 分析，但文字和细节容易看不清。试了几个工具，都不够方便，于是自己做了 Pic2Pics。

**一张长图，自动拆分，一键导出。**

- 图片在浏览器本地处理，无需上传
- 支持粘贴、拖入图片
- 自定义分图数量、高度及重叠区域
- 适配电脑和手机浏览器（移动端仍需持续测试）
